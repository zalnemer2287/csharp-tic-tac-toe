# Tic Tac Toe (C#)

A desktop Tic Tac Toe game built using C# and Windows Forms.

## Features
- Interactive GUI using Windows Forms
- Two-player gameplay
- Game state tracking and win detection
- Event-driven input handling
- Reset / replay functionality

## Tech Stack
- C#
- .NET Framework
- Windows Forms

## Project Structure
- `Program.cs` – application entry point
- `Form1.cs / Form2.cs` – UI and game logic
- `.csproj` – project configuration

## How to Run

### Option 1 (Recommended)
1. Open `TicTacToe.csproj` in Visual Studio
2. Build and run using **F5**

### Option 2
Ensure .NET Framework is installed, then build and run via Visual Studio

## Notes
- Originally built targeting an older .NET Framework version
- May require retargeting to a newer version (e.g., 4.6.1+) when opening in modern Visual Studio
